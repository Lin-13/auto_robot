# Robot Interface

Robot Interface主要定义了一些通用的机器人控制框架，用于实现不同工业机器人与算法的耦合。为了尽可能轻量化，其仅仅包含机器人进行高级运动控制的必要内容。

RobotInterface控制对象为工业机器人，其控制功能通过机器人本体实现，而RobotInferface仅仅提供一种通用的机器人控制抽象，其底层实现仍然是机器人SDK或者ROS。

其主要分为下面几个特性：

1、通过RobotController对机器人发送位置指令，实现对机器人运动的高级控制。RobotController的的实现应当是异步的，即调用者仅仅需要指定机器人的高级状态（运动和速度或其他)，其状态由控制其自身保持。而RobotController仅仅向底层发送位置/关节指令，因此运动控制的准确性由机器人本体决定。

2、通过RobotTopology进行机器人运动学分析，包括正逆运动学、Jacobi矩阵等，这是进行机器人复杂控制的核心，使上层代码能够了解机器人特性并实现位置控制之外更加高级的运动特性。注意不分析其动力学特性，因为其不应该被上层控制。

3、通过RobotIO实现上层对机器人状态的读取。RobotIO本身实现，是沟通Controller和上层代码的桥梁。因为Controller被设置成异步的，上层不应该直接越过Controller读取底层信息，也不应该直接向Controller索取信息——这会导致控制其潜在的阻塞。在底层方面为了实现通用性，机器人本体只需提供关节位置和速度的读取，而更多的转台则由RobotCOntrooller本身决定。RobotIO不应该写入，写入应该由Controller实现。
